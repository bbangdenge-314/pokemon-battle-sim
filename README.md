# ⚔️ 포켓몬 배틀 시뮬레이터 · Pokémon Battle Simulator

1~9세대 **전국도감 1,025마리**가 실제로 배우는 기술과 타입 상성, 날씨 보정으로 싸우는 **오토 배틀 시뮬레이터**입니다.
장소와 날씨, 팀을 고르면 배틀이 알아서 펼쳐지고, 결과 화면에서 승패 · MVP · 데미지 통계를 확인할 수 있습니다.

**▶ 플레이: https://bbangdenge-314.github.io/pokemon-battle-sim/**

---

## 주요 기능

### 1. 1~9세대 1,025마리
* 한국어 이름 · 영어 이름 · 도감번호 · 세대 · 타입 · 종족값(HP/공격/방어/특공/특방/스피드)
* **실제 학습 기술 중 대표 기술 4개**를 자동 선정 (자속 기술 우선 + 타입 견제 다양성 + 우선도 기술 가점)
  * 피카츄 → 10만볼트 · 전광석화 · 아이언테일 · 볼트태클
  * 이상해꽃 → 솔라빔 · 잎날가르기 · 오물폭탄 · 수면가루
  * 뮤츠 → 사이코브레이크 · 섀도볼 · 파동탄 · HP회복
* 검색(한국어/영어/도감번호) · 세대 필터 · 타입 필터 · 랜덤 팀 채우기
* 공식 아트워크 스프라이트 + PokeAPI 울음소리(ogg), 실패 시 픽셀 스프라이트 → 도형 폴백

### 2. 5단계 진행
1. **대결 방식** — 1 vs 1 / 2 vs 2 / 3 vs 3 (한 마리가 쓰러지면 다음 포켓몬 자동 투입)
2. **장소** — 스타디움 · 해변 · 바위산 · 설산 · 숲 · 화산 · 밤 도심 · 우주 · 신전 · 수정 동굴 · 사막 (11종)
3. **날씨** — 맑음 · 쾌청 · 비 · 모래바람 · 싸라기눈
4. **포켓몬 선택** — 양 팀 슬롯, 도감 모달, 랜덤 채우기 (모두 Lv.50 고정)
5. **프리뷰** — 레이더 차트 · 능력치 비교 바 · 기술별 실효 위력/상성 · 예상 승률 → 전투 시작

### 3. 배틀 연출
* Canvas로 그리는 11종 배경 — 파도, 구름, 불티, 별, 반딧불, 네온 창문, 오로라 등 움직이는 요소
* 날씨 파티클(빗줄기·모래·싸라기눈·햇빛 광선)이 배경과 배틀에 동시 반영
* 포켓몬 애니메이션: 등장 드롭 · 대기 호흡 · 공격 돌진(잔상) · 피격 흔들림/플래시 · 기절 연출
* 타격감: 히트스톱(화면 플래시) · 카메라 셰이크 · 급소/효과 굉장함 배너 · 데미지 팝업 · 타입별 파편
* 배속 1x/2x/3x · 일시정지 · 결과 바로 보기

### 4. 기술별 고유 연출 (Canvas 파티클)
기술을 아키타입으로 분류해 타입 색상·형태를 입힙니다. (총 228종의 기술 데이터, 15종 아키타입)

| 아키타입 | 예시 기술 | 연출 |
|---|---|---|
| beam | 솔라빔, 냉동빔, 문포스, 철제광선 | 차징 오브 → 굵어지는 빔 + 에너지 링/필라멘트 |
| stream | 화염방사, 하이드로펌프 | 노즐 화염 + 부채꼴 파티클 분사 |
| bolt | 10만볼트, 번개 | 지그재그 낙뢰 + 가지 + 스파크 (하늘낙뢰 지원) |
| projectile | 섀도볼, 파동탄, 오물폭발 | 궤적을 그리며 날아가는 구체 + 폭발 |
| volley | 잎날가르기, 불릿시드, 스톤에지 | 회전하는 나뭇잎/씨앗/돌 다발 |
| slash | 리프블레이드, Dragon Claw, X-Scissor | 회전하는 참격 궤적 |
| rush | 인파이트, 볼트태클, 신속 | 잔상 돌진 + 연속 타격 |
| drop | 스톤에지, 지진 | 하늘에서 떨어지는 암석 + 균열/충격파 |
| quake | 지진, 땅고르기 | 지면 균열 · 파편 · 먼지 · 충격 링 |
| wave | 사이코키네시스, 파도타기 | 확산하는 충격 링 |
| meteor | 용성군, 미래예지 | 불꽃 꼬리를 그리는 유성 |
| storm | 눈보라, 폭풍 | 소용돌이 + 눈/바람 파티클 |
| buff / heal / status / shield | 칼춤, HP회복, 수면가루, 방어 | 오라 링, 상승 파티클, 가루 확산, 방어막 |

### 5. 실제 배틀 규칙
* Lv.50 · 개체값 31 · 노력치 0 · 중립 성격 기준 능력치 산출
  * 관전형 배틀이라 한 방에 끝나지 않도록 **체력만 1.6배 보정**(UI·README에 표기). 그 외 능력치와 데미지 공식은 정규 규칙 그대로
* 5세대 이후 데미지 공식 + 자속 1.5배 + 타입 상성(4x~0x) + 급소(1/16, 1.5배) + 난수 0.85~1.0
* **날씨**: 쾌청(불꽃 1.5·물 0.5) / 비(물 1.5·불꽃 0.5) / 모래바람(바위 특방 1.5, 매 턴 1/16) / 싸라기눈(얼음 방어 1.5, 매 턴 1/16)
* **상태이상**: 화상(물리 0.5, 턴 피해) · 마비(스피드 0.5, 25% 행동불가) · 독 · 잠듦 · 얼음
* **랭크 변화**: 칼춤·나쁜음모·명상·용의춤·껍질깨기 등, 인파이트/오버히트/용성군 자기 하락
* **부가효과**: 화상/마비/얼음/풀죽음/혼란 유발, 방어·특방 하락, 흡수(giga-drain), 반동, 2~5연타, 급소율 상승
* **교체**: 쓰러지면 다음 포켓몬 자동 투입, 승패 · MVP(총 피해) · 팀별 데미지 통계 집계
* **AI**: 상성·자속·날씨·남은 HP를 고려한 기대 데미지 + 회복/랭크업/상태이상의 상황 판단 + 상위 후보 가중 랜덤

## 파일 구조

```
pokemon-battle-sim/
├── index.html            # 5단계 설정 · 배틀 · 결과 · 도감 모달
├── css/style.css         # 전체 UI (다크 글래스 테마, 반응형)
├── js/
│   ├── data.js           # 1,025종 도감 + 228 기술 + 타입 상성 (자동 생성)
│   ├── engine.js         # 배틀 시뮬레이션(순수 로직) · 데미지 · AI · 이벤트
│   ├── fx.js             # 기술별 Canvas 이펙트 (15 아키타입, 파티클)
│   ├── scenes.js         # 11종 배경 일러스트 + 날씨 파티클
│   ├── battle-ui.js      # 이벤트 재생, 스프라이트/HUD/팝업, 결과 화면
│   ├── sprites.js        # 아트워크·울음소리 로딩, WebAudio 효과음
│   ├── icons.js          # 인라인 SVG 아이콘
│   └── main.js           # 화면 흐름 · 팀 선택 · 프리뷰
├── data/csv/             # (개발용) PokeAPI CSV 원본 — 저장소에는 미포함
└── tools/
    ├── build_data.py     # CSV → js/data.js 생성 스크립트
    └── *.py              # Playwright 검증 스크립트
```

### 데이터 재생성
```bash
mkdir -p data/csv && cd data/csv
for f in pokemon pokemon_species pokemon_species_names pokemon_types pokemon_stats \
         pokemon_moves moves move_names type_efficacy types type_names; do
  curl -sO "https://raw.githubusercontent.com/PokeAPI/pokeapi/master/data/v2/csv/$f.csv"
done
cd ../.. && python3 tools/build_data.py
```
데이터 출처: [PokeAPI](https://pokeapi.co) (CSV 스냅샷), 스프라이트 [PokeAPI/sprites](https://github.com/PokeAPI/sprites), 울음소리 [PokeAPI/cries](https://github.com/PokeAPI/cries).
포켓몬스터는 닌텐도·게임프리크·크리에이쳐스의 상표이며, 이 프로젝트는 비공식 팬 프로젝트입니다.

## 알려진 제한
* 스프라이트·울음소리는 PokeAPI CDN에서 불러오므로 첫 로딩 시 네트워크가 필요합니다(이후 브라우저 캐시).
* 1세대 일부 포켓몬(메타몽·안농 등)은 공격 기술이 1~2개뿐이라 기술 슬롯이 비어 보일 수 있습니다. 실제 학습 데이터를 그대로 반영한 결과입니다.
* 기술의 차지/재충전 턴은 배틀 템포를 위해 생략하고 위력만 반영했습니다.
