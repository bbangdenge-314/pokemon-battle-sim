# ⚔️ 포켓몬 배틀 시뮬레이터 · Pokémon Arena Battle Simulator

1~9세대 **전국도감 1,025마리**가 실제로 배우는 기술과 타입 상성, 날씨 보정으로 싸우는 **실시간 아레나 난투 시뮬레이터**입니다.
포켓몬은 2.5D 쿼터뷰 아레나를 직접 뛰어다니며 거리를 재고, 기술을 쏘고, 날아오는 공격을 회피합니다.
상단에서는 **캐스터와 해설**이 실시간으로 중계합니다.

**▶ 플레이: https://bbangdenge-314.github.io/pokemon-battle-sim/**

---

## 주요 기능

### 1. 1~9세대 1,025마리
* 한국어 이름 · 영어 이름 · 도감번호 · 세대 · 타입 · 종족값(HP/공격/방어/특공/특방/스피드)
* **실제 학습 기술 중 대표 기술 4개**를 자동 선정 (자속 기술 우선 + 타입 견제 다양성 + 우선도 기술 가점)
  * 피카츄 → 10만볼트 · 전광석화 · 아이언테일 · 볼트태클
  * 이상해꽃 → 솔라빔 · 잎날가르기 · 오물폭탄 · 수면가루
  * 뮤츠 → 사이코브레이크 · 섀도볼 · 파동탄 · HP회복
* 검색(한국어/영어/도감번호) · 세대 필터 · 타입 필터 · 랜덤 팀 채우기
* 공식 아트워크 스프라이트 + PokeAPI 울음소리(ogg), 실패 시 픽셀 스프라이트 → 도형 폴백

### 2. 5단계 진행
1. **대결 방식** — 1 vs 1(2마리) / 2 vs 2(4마리) / 3 vs 3(6마리) **전원 동시 출격**
2. **장소** — 스타디움 · 해변 · 바위산 · 설산 · 숲 · 화산 · 밤 도심 · 우주 · 신전 · 수정 동굴 · 사막 (11종 아레나)
3. **날씨** — 맑음 · 쾌청 · 비 · 모래바람 · 싸라기눈
4. **포켓몬 선택** — 양 팀 슬롯, 도감 모달, 랜덤 채우기 (모두 Lv.50 고정)
5. **프리뷰** — 레이더 차트 · 능력치 비교 · 기술별 실효 위력/상성 · 예상 승률(실시간 엔진 헤드리스 시뮬레이션)

### 3. 실시간 아레나 난투
* **태그 매치 없음** — 2 vs 2는 4마리, 3 vs 3은 6마리가 한 필드에서 동시에 교전합니다
* 각 포켓몬은 아레나 좌표 `(x, y)`를 가지고 자유롭게 이동
  * **원거리형**: 사거리 유지 · 카이팅 (적이 붙으면 뒤로 빠지며 스트레이프)
  * **근접형**: 돌진 · 측면 기동 (사거리 안으로 파고들어 연타)
  * 아군끼리 겹치지 않는 분리 벡터 + 아레나 경계 소프트 리펄스 + 대치 시 좌우 스트레이프
* **능력치가 그대로 전투에 반영**
  * 스피드 → 이동 속도 · 기술 쿨타임 회전율 · 회피 반응(대시 거리/판정)
  * 공격/특공 · 방어/특방 · HP → 실제 데미지 공식과 기술 사거리·차징
  * 빠른 포켓몬(피카츄·뮤츠·드래펄트)은 휙휙 움직이며 잘 피하고, 느린 포켓몬(잠만보·마기라스·거북왕)은 묵직하게 이동
* **실제 회피 판정** — 날아오는 투사체·돌진·장판을 좌표로 판정. 사이드스텝으로 벗어나면 `회피!` 텍스트 + 잔상과 함께 **노데미지**
  * 명중률 · 스피드 차이 · 쿨타임에 따라 회피 시도 빈도가 달라집니다
  * 장판(지진·눈보라·유성)은 텔레그래프를 보고 실제로 빠져나갈 수 있습니다
* **머리 위 기술 말풍선** — `"10만볼트!"`, `"나뭇잎베기!"`, `"물대포!"`처럼 타입 색 포인트가 있는 말풍선이 뜨고, 여러 마리가 동시에 써도 겹치지 않게 자동으로 쌓입니다
* **상단 캐스터 · 해설 중계** — 개전 인사, 선제공격, 회피 슈퍼플레이, 효과 굉장함/급소, 한타, 퍼스트 블러드, 위기, 역전, 서든데스, 경기 종료 MVP까지 실제 이벤트에 반응해 두 사람의 멘트가 번갈아 흐릅니다

### 4. 15종 기술 아키타입 (아레나 좌표 기반 발사)
기술을 아키타입으로 분류해 타입 색상·형태를 입히고, **실제 `(x1,y1) → (x2,y2)` 사이**에서 발사·판정합니다.

| 아키타입 | 예시 기술 | 연출 |
|---|---|---|
| beam | 솔라빔, 냉동빔, 문포스, 철제광선 | 발사 섬광 → 굵어지는 빔 + 명중 섬광 |
| stream | 화염방사, 하이드로펌프 | 부채꼴 분사 + 광역 판정 |
| bolt | 10만볼트, 번개 | 하늘에서 갈라지는 낙뢰 + 임팩트 섬광 |
| projectile | 섀도볼, 파동탄, 오물폭발 | 유도 궤적 구체 + 폭발 |
| volley | 잎날가르기, 불릿시드, 스톤에지 | 다발 발사 (2~5연타) |
| slash / rush / bite | 리프블레이드, 인파이트, 물기 | 돌진 + 참격/이빨 연출, 근접 판정 |
| drop / quake / meteor | 스톤에지, 지진, 용성군 | 낙하 · 지면 균열 · 유성 (장판 텔레그래프) |
| storm | 눈보라, 폭풍 | 회오리 장판 (3회 틱) |
| wave | 사이코키네시스, 파도타기 | 확산 충격 링 |
| burst / pillar / shadow / cage | 열풍, 블라스트번, 섀도다이브, 전기자석 | 폭발 · 광주 · 그림자 · 감전 감옥 |
| buff / heal / status / shield | 칼춤, HP회복, 수면가루, 방어 | 오라 · 회복 파티클 · 가루 · 방어막 |

### 5. 2.5D 쿼터뷰 아레나 (11종)
* 상단 23%는 원경(관중석·바다 수평선·산맥·네온 스카이라인·성운·신전·종유석·모래언덕), 나머지 **77%는 포켓몬이 실제로 이동하는 플레이어블 바닥**
* 장소별 바닥 재질(잔디·모래·빙판·용암·대리석·육각 플랫폼·수정 동굴·모래언덕)과 원근 격자, 경계선, 중앙선·센터 서클, 팀 진영 표시
* 충돌 없는 장식물(깃발·야자수·바위·수정·횃불·기둥·네온 간판·위성 등)이 깊이 순서대로 포켓몬과 함께 정렬되어 그려집니다
* 날씨 파티클(빗줄기·모래·싸라기눈·햇빛)과 스테이지 앰비언트(불티·반딧불·눈·먼지·별·네온)

### 6. 실제 배틀 규칙
* Lv.50 · 개체값 31 · 노력치 0 · 중립 성격 기준 능력치 산출
* 5세대 이후 데미지 공식 + 자속 1.5배 + 타입 상성(4x~0x) + 급소(1/16, 1.5배) + 난수 0.85~1.0
* **아레나 난투 밸런스** — 실시간 교전에 맞춰 체력을 추가 보정하고(모드별 배율), 피해를 소폭 조정. 경기 시간이 길어지면 **서든데스**(공격력 점증)로 반드시 결말이 납니다
  * 24개 랜덤 매치업 벤치마크: 1v1 중앙값 23초 / 2v2 25초 / 3v3 24초 (10~90% 구간 12~33초)
* **날씨**: 쾌청(불꽃 1.5·물 0.5) / 비(물 1.5·불꽃 0.5) / 모래바람(바위 특방 1.5, 2.6초마다 1/22) / 싸라기눈(얼음 방어 1.5, 2.6초마다 1/22)
* **상태이상**: 화상(물리 0.5, 지속 피해) · 마비(스피드 0.5, 20% 기술 불발) · 독 · 잠듦 · 얼음 · 풀죽음 · 혼란
* **랭크 변화**: 칼춤·나쁜음모·명상·용의춤·껍질깨기 등, 인파이트/오버히트/용성군 자기 하락 → 이동 속도와 데미지에 실시간 반영
* **부가효과**: 화상/마비/얼음/풀죽음/혼란 유발, 방어·특방 하락, 흡수, 반동, 2~5연타, 급소율 상승
* **AI**: 상성·자속·날씨·거리·남은 HP를 고려한 기대 데미지 + 회복/랭크업/상태이상 판단 + 상위 후보 가중 랜덤, 대상 재선택과 카이팅
* **결과**: 승패 · 소요 시간 · MVP(피해+KO+회피+회복) · 팀별 피해 통계 · 회피 횟수 · 전투 로그

## 구조

```
index.html            # 인트로 · 5단계 설정 · 배틀(캐스터 바/아레나 캔버스) · 결과
css/style.css         # 전체 UI (아레나 HUD · 중계 바 포함)
js/data.js            # 1,025종 · 228기술 데이터 (PokeAPI CSV 스냅샷)
js/engine.js          # 능력치/데미지 공식/타입 상성/날씨 (코어 규칙)
js/arena.js           # 실시간 난투 엔진 (이동·쿨타임·투사체·장판·회피·AI)
js/arena-scenes.js    # 2.5D 쿼터뷰 아레나 배경 11종 + 필드 좌표 투영
js/battle-ui.js       # 60fps 렌더러 (포켓몬·말풍선·이펙트·HP바·중계·결과)
js/commentary.js      # 캐스터/해설 멘트 뱅크 + 이벤트 반응
js/fx.js              # 기술 아키타입 스펙 테이블 (색·형태)
js/sprites.js         # 아트워크/울음소리/효과음
js/scenes.js          # 인트로 히어로 배경
js/main.js            # 화면 흐름 · 팀 선택 · 프리뷰
tools/verify_arena.py # Playwright 실브라우저 검증 (PC·모바일 스크린샷)
tools/smoke_arena.py  # 빠른 전투 스모크 테스트
```

## 검증

```bash
python3 tools/verify_arena.py   # PC 1440×900 · 모바일 390×844, 1v1/2v2/3v3
```

콘솔 에러 0건, 결과 화면까지 도달하는지 확인하고 스크린샷과 `verify_v3_report.json`을 `downloads/pokemon-battle-sim/`에 남깁니다.
